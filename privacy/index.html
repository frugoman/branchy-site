Privacy

The app

Branchy runs git on your machine using your own git config. API keys for AI providers are stored in the macOS Keychain. Branchy talks to GitHub and to the AI provider you choose, using your own credentials; Frusoft receives none of your code, tokens or data.

This website

With your consent only, this website uses Google Analytics to measure anonymous page views, clicks on download buttons and how far guides are read. We never send names, emails or free text. Analytics stays off until you click Accept, and nothing is sent if your browser sends Do Not Track. Choose Decline on the banner, or clear this site's data, to opt out.
