Worktrees first

Work on three branches without stashing once.

Each worktree is a station on the line, with its changes, its ahead and behind count, and the state of its pull request. Switching is one click, and a new one is two.

Conflicts, handled

“This branch has conflicts” is one click.

Branchy puts the PR's branch in a worktree, merges the base into it and opens the conflicts. Keep yours, take theirs, or open the file in your editor, then push.

A history you can read

Forty branches, one calm graph.

Commits ride a transit map. In a busy repo, keep a few lines in colour and bundle the rest into one, so you can read the commit titles again.

Get on the line.

Branchy is free. It uses your own git, so your config, credentials and hooks work exactly like in the terminal. Sign in to GitHub with the GitHub CLI or a token.
